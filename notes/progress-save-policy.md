# Сохранение прогресса экзамена

Реализация автосохранения прогресса экзамена должна быть ограничена только случаями программного сбоя.

## Условие
- Если приложение внезапно закрывается, зависает, перезагружается или завершает работу некорректно, система должна сохранять текущий прогресс.
- Если пользователь завершил экзамен нормально, прогресс не сохраняется как активный сеанс.
- Если пользователь просто переключил страницу или завершил тест вручную, данные не должны восстанавливаться автоматически.

## Логика
- Сохранять текущий вопрос, выбранные ответы, таймер и статус экзамена в локальное хранилище при критическом сбое.
- При повторном запуске приложения восстанавливать только те сессии, которые были прерваны по ошибке программы.
- Не восстанавливать данные после обычного завершения экзамена или ручного выхода по кнопке "Завершить тест" / "Вернуться".

## Цель
- Защитить результаты пользователя при техническом сбое.
- Не создавать ложное впечатление, что экзамен можно продолжить после нормального завершения.
- Избежать некорректного восстановления сессии в обычных сценариях использования.
